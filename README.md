# 双科目刷题系统（公共基础 + 岩土专业基础）
基于 Vue3 + Vite 开发的纯前端单选题刷题应用，适配 Windows 电脑端、苹果手机 Safari 移动端，无需后端服务，所有数据本地浏览器持久化存储，搭配 Git 本地版本管理，专注岩土考试真题刷题训练。

## ✨ 项目核心功能
- **双科目隔离**：区分【公共基础】【专业基础】两大科目，题目、年份、题号完全独立隔离，互不混淆
- **双刷题模式**：支持 **按小科目刷题** / **按年份刷题** 两种模式自由切换
- **完整答题交互**：ABCD单选题作答，提交后弹窗展示正确答案+详细解析，提交后锁定选项防止重复修改
- **精准进度保存**：浏览器本地缓存持久化记录刷题进度、当前科目/模式/题号，关闭页面重启自动恢复
- **分类错题本**：自动收集错题，区分两大科目错题，支持针对性错题复盘刷题
- **分段正确率统计**：完成单个小科目 / 单个年份全部题目后，自动计算并展示当前板块正确率及答题汇总
- **复杂内容渲染**：支持普通文本、HTML表格、KaTeX数学公式、图片渲染，适配考试真题格式
- **全端自适应**：适配电脑大屏、苹果手机移动端，触摸交互友好

## 🛠 技术栈
- 核心框架：Vue3 + Vite（轻量、极速启动）
- 公式渲染：KaTeX（适配真题数学/工程公式）
- 本地存储：LocalStorage（进度、错题、答题记录持久化）
- 版本管理：Git（本地完整版本控制）
- 运行环境：纯前端静态页面，无后端依赖

## 📊 题库数据说明
### 1. 题库来源
- 公共基础：本地PDF真题（13~24年）题目+答案解析
- 专业基础：岩土专业本地PDF真题（16~24年）题目+答案解析
- 题目与答案解析顺序一一对应，无错乱

### 2. 题库JSON标准字段
```json
{
  "id": 题号（单科目内独立编号）,
  "bigSubject": "大科目（公共基础/专业基础）",
  "smallSubject": "小科目细分",
  "year": "真题年份",
  "question": "题干（支持文字/表格/LaTeX公式/img图片标签）",
  "A": "A选项内容",
  "B": "B选项内容",
  "C": "C选项内容",
  "D": "D选项内容",
  "answer": "正确答案（仅大写ABCD）",
  "analysis": "答案解析（支持公式渲染）"
}
```

### 3. 特殊内容处理规则

- 表格：自动转为HTML表格，适配页面渲染
- 公式：转为 LaTeX 格式，`$公式内容$` 包裹，KaTeX自动渲染
- 配图：使用 `<img src="/images/q{id}.png" style="max-width:100%;">` 标签引入图片；图片文件放在项目 `public/images/` 目录；页面自动缩放图片适配电脑与手机屏幕。

## 💻 本地运行 & 打包


## 📌 核心使用流程

1. 进入首页，选择**大科目**（公共基础/专业基础），两大科目数据完全隔离
2. 选择**刷题模式**：按小科目刷题 / 按年份刷题
3. 选中对应小科目/年份，进入刷题页面开始作答
4. 选择选项并提交，查看标准答案与详细解析
5. 完成当前板块所有题目，自动查看正确率与答题统计
6. 错题自动收录，可进入错题本专项刷题复盘
7. 关闭页面自动保存进度，下次打开接续刷题

## 🔧 Git 提交规范（项目专用）

统一提交格式：`<type>: <中文简短描述>`

- `feat`：新增功能
- `fix`：修复功能Bug
- `data`：更新题库JSON数据
- `style`：UI样式、移动端适配优化
- `refactor`：代码重构优化（无功能变更）
- `chore`：工程配置、忽略文件修改
- `docs`：文档更新

示例：`git commit -m "feat: 实现按年份刷题模式，双科目数据隔离"`

## ⚠️ 注意事项

- 所有刷题进度、错题数据存储在**浏览器本地**，清除浏览器缓存会丢失数据
- 公共基础与专业基础题号、年份相互独立，刷题数据完全隔离，不会交叉混淆
- 题库更新仅需替换 `src/data/questions.json` 文件，无需修改业务代码
- 禁止提交 `node_modules`、`dist`、本地图片等冗余文件（已配置.gitignore）
